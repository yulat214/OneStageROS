# ターミナル

画面右上の **ターミナル** ボタンで、画面下部にターミナルを開きます。
「シミュレータ」「エディター」のどちらのタブからでも使用できます。

---

## 使い方

- OneStageROS を起動したユーザーのシェルが、ホームディレクトリで起動します。
- OneStageROS を起動したターミナルの環境変数を引き継ぐため、`source` 済みの ROS 2 環境でそのまま `ros2` コマンドを使えます。
- ターミナルの上端をドラッグすると、高さを変更できます。
- ✕ ボタンまたは **ターミナル** ボタンでパネルを閉じても、シェルは終了しません。もう一度開くと続きから操作できます。
- ページを再読み込みすると、シェルは終了します。

---

## 使用例

```bash
# トピックの一覧を確認する
ros2 topic list

# キーボードでロボットを操作する
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# SLAM を起動する
ros2 launch slam_toolbox online_async_launch.py
```
