# エディター・ビルド

「エディター」タブでは、ホームディレクトリ内のファイルを編集し、ROS 2 ワークスペースのビルドと実行ができます。

---

## ファイルツリー

画面左側に、ホームディレクトリ（`~`）以下のファイルとフォルダを表示します。

| 操作 | 動作 |
|------|------|
| フォルダをクリック | フォルダの中に移動 |
| 「.. (上の階層へ)」 | 1 つ上のフォルダに移動 |
| ファイルをクリック | エディターで開く |
| 📄+ ボタン | 新しいファイルを作成 |
| ⟳ ボタン | 一覧を更新 |

- 名前が `.` で始まるファイル・フォルダは表示されません。
- 新しいファイルは、ファイル名を入力して `Enter` で作成します（`Esc` でキャンセル）。`launch/my.launch.py` のようにフォルダを含めて入力すると、フォルダも作成されます。

---

## コードエディター

ファイルを開くと、画面右側のエディターで編集できます。VS Code と同じ Monaco Editor を使用しています。

- ファイルの種類（Python / C++ / XML / URDF / YAML / CMake など）に合わせて色分け表示します。
- 編集後、右上の **保存** ボタン、または `Ctrl+S`（macOS では `Cmd+S`）で保存します。
- 保存したファイルには実行権限が付与されます。Python のノードをそのまま実行できます。
- 編集できるファイルの大きさは 2 MB までです。

---

## ビルド

エディターの下にあるビルドパネルで、`colcon build` を実行します。

1. ワークスペースの欄に、ビルドするワークスペースのパスを入力します（例: `~/ros2_ws`）。入力した値はブラウザに保存されます。
2. **実行** を押すと、ワークスペースで `colcon build` を実行します。
3. ビルドのログがパネルに表示され、終了すると「成功」「失敗」が表示されます。

ビルド中・実行中は **中断** ボタンで停止できます。
「ビルド」の見出しを押すと、ログ表示を開閉できます。

### 詳細オプション

⚙ ボタンで詳細オプションを表示します。

| オプション | 説明 |
|------------|------|
| パッケージ名 | ビルドするパッケージを指定します（`--packages-select`）。カンマ区切りで複数指定できます。空欄の場合はすべてのパッケージをビルドします。 |
| `--symlink-install` | シンボリックリンクでインストールします。Python ファイルの変更が再ビルドなしで反映されます。（既定: オン） |
| ファイル保存時に自動ビルド | エディターで保存するたびにビルドを実行します。 |
| ビルド成功後に実行 | ビルドが成功したら、指定したコマンドを実行します。 |

### ビルド成功後に実行

「ビルド成功後に実行」をオンにすると、コマンドの入力欄が表示されます。

```text
ros2 launch my_pkg my_launch.py
```

- コマンドは、ワークスペース欄で指定したワークスペースの `install/setup.bash` を読み込んだうえで、ホームディレクトリで実行されます。
- コマンドの出力は、ビルドのログに続けて表示されます。
- 実行中のコマンドは **中断** で停止できます（`Ctrl+C` と同じシグナルを送ります）。
