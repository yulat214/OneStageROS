# ワールド編集

シミュレータに障害物や物体を配置して、ロボットを動かす環境を作れます。
配置したオブジェクトは [LiDAR](simulator.md#lidarscan) や [カメラ](camera.md) に映り、[把持](simulator.md#物体の把持) の対象にもなります。

シミュレータのヘッダーにある **ワールド編集** ボタンで、編集パネルを開閉します。

---

## オブジェクトを配置する

### 基本図形

編集パネルの「配置」にあるボタンで、基本図形を配置します。

| ボタン | 図形 | 大きさ |
|--------|------|--------|
| □ Box | 立方体 | 1 m × 1 m × 1 m |
| ⬭ Cyl | 円柱 | 半径 0.3 m、高さ 0.5 m |
| ○ Sph | 球 | 半径 0.3 m |

### ファイルから配置

「ファイルから配置」を押すと、ホームディレクトリ以下のファイルを選ぶ画面が開きます。
以下の形式のファイルを配置できます。

| 形式 | 拡張子 |
|------|--------|
| メッシュ | `.dae` / `.obj` / `.stl` / `.glb` / `.gltf` |
| SDF（Gazebo のモデル・ワールド） | `.sdf` / `.world` / `.model` |

- `.obj` に `.mtl`（マテリアル）が指定されている場合は、同じフォルダの `.mtl` も読み込みます。
- SDF は、含まれる `<visual>` のメッシュ・箱・円柱・球を、`<material>` の色とともに配置します。
- SDF の `<include>` で指定された `model://` は、環境変数 `GAZEBO_MODEL_PATH` と `/usr/share/gazebo*/models` から探します。`ground_plane` と `sun` は読み込みません。

### 配置の操作

図形やファイルを選ぶと配置モードになり、カーソルの位置に半透明のプレビューが表示されます。

| 操作 | 動作 |
|------|------|
| マウス移動 | 配置位置を移動 |
| ホイール | 向きを回転（画面上部に角度を表示） |
| 左クリック | その位置に配置 |
| 右クリック／`Esc` | 配置をキャンセル |

## オブジェクトを移動・削除する

### 3D ビューから操作する

3D ビュー上のオブジェクトをクリックすると、青い枠で選択され、メニューが表示されます。

- **移動**: オブジェクトがカーソルに追従します。ホイールで回転し、左クリックで確定します。右クリック／`Esc` で元の位置に戻ります。高さは変わりません。
- **削除**: オブジェクトを削除します。

### 一覧から操作する

編集パネルの「オブジェクト」を開くと、配置済みのオブジェクトが一覧表示されます。各行の「移動」「削除」ボタンで操作できます。
「すべて消去」で、すべてのオブジェクトを削除します。

### 固定オブジェクト

名前に `wall`・`floor`・`ceiling`・`roof`・`ground` を含むオブジェクト（壁・床・天井など）は固定オブジェクトとして扱われます。
固定オブジェクトはクリックで選択できず、移動もできません（一覧から削除することはできます）。

---

## 環境を保存・読み込みする

編集パネルの「環境」から操作します。

| ボタン | 動作 |
|--------|------|
| 保存 | 配置中のオブジェクトを `environment_layout.json` としてダウンロードします。 |
| 呼び出し | 保存した JSON ファイルを選んで、オブジェクトを読み込みます。現在のオブジェクトは置き換えられます。 |
| 地面の色 | 床の色を変更します。 |

配置したオブジェクトはブラウザにも自動保存され、ページを再読み込みしても維持されます。
OneStageROS を再起動すると自動保存された内容は消えるため、残したい環境は「保存」でファイルに書き出してください。

---

## ワールドファイルを起動時に読み込む

`server/.env` の `ONESTAGE_WORLD` に `.sdf` / `.world` ファイルを指定すると、OneStageROS の起動時にそのワールドを読み込みます。
ROS 2 の launch で `world:=` を指定するのと同じ感覚で使えます。

```bash
# server/.env
ONESTAGE_WORLD=ros2_ws/src/my_pkg/worlds/room.world
```

- パスはホームディレクトリからの相対パス、またはホームディレクトリ以下の絶対パスで指定します。
- ワールドの原点がシミュレータの原点に合わせて配置されます。
- ワールドを読み込んでいるときの **リセット** ボタンは、ロボットとオブジェクトをワールドの初期状態に戻します（編集内容は破棄されます）。
- 編集した状態はワールドごとにブラウザへ自動保存され、ページを再読み込みすると続きから再開できます。

### ロボットの初期位置

ロボットの初期位置は、以下の優先順で決まります。

1. `server/.env` の `ONESTAGE_SPAWN`
2. ワールドファイル内の、名前が `robot` または `spawn` の `<model>` の `<pose>`（このモデル自体は表示されません）
3. ワールドファイル内の、最初の `<include>`（`ground_plane`・`sun` を除く）の `<pose>`
4. 原点（0, 0, 0）

`ONESTAGE_SPAWN` は `"x y yaw"`（単位: m, m, rad）の形式で、空白またはカンマで区切ります。`yaw` は省略できます。

```bash
# server/.env
ONESTAGE_SPAWN=0.5 -1.0 1.57
```

`ONESTAGE_SPAWN` は `ONESTAGE_WORLD` を指定しないときにも使用でき、その場合は **リセット** でこの位置に戻ります。
