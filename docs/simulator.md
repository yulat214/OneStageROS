# シミュレータ

「シミュレータ」タブの左側に表示される 3D ビューです。
ROS 2 で起動しているロボットのモデルを表示し、関節角度や速度指令に合わせて動かします。
物理演算は行わず、ロボットの動作確認に特化した軽量な表示を行います。

---

## ロボットの表示

`robot_state_publisher` が起動していると、そのパラメータ `robot_description` からロボットモデルを読み込んで表示します。

- ロボットを起動していない場合は何も表示されません。起動すると数秒以内に自動で表示されます。
- ロボットを停止しても、最後に表示したロボットはそのまま残ります。再び起動すると、ロボットのモデルを自動で読み込み直します。
- メッシュファイル（`.stl` / `.dae` / `.obj` / `.glb` / `.gltf`）は、`package://` で指定されたパッケージから読み込みます。

ヘッダー右端の **Status** は ROS Bridge との接続状態です（`Connected` / `Disconnected` / `Error`）。

## 視点の操作

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点を回転 |
| 右ドラッグ | 視点を平行移動 |
| ホイール | ズーム |

## ロボットの動き

### 関節

`/joint_states` を受信すると、同じ名前の関節に角度を反映します。

### 走行

`/cmd_vel` の `linear.x`（前進速度）と `angular.z`（旋回速度）に従って、ロボットを床の上で移動させます。

- `teleop_twist_keyboard` などで `/cmd_vel` を送ると、そのまま 3D ビュー上のロボットが走行します。
- URDF に `world` という名前のリンクがあるロボット（台に固定されたアームなど）は、固定ロボットとして扱い、`/cmd_vel` を受けても移動しません。

### 停止・リセット

| ボタン | 動作 |
|--------|------|
| 停止／再開 | ロボットの走行を一時停止します（オドメトリの速度は 0 になります）。もう一度押すと再開します。 |
| リセット | ロボットを初期位置に戻し、速度を 0 にします。ワールドファイルを読み込んでいる場合は、確認のあとロボットとオブジェクトをワールドの初期状態に戻します。 |

ロボットの位置はブラウザに自動保存され、ページを再読み込みしても維持されます。
OneStageROS を再起動すると初期位置に戻ります。

## 仮想センサー

シミュレータは、ロボットの位置と配置したオブジェクトをもとに、以下の情報を ROS 2 に配信します。
LiDAR・オドメトリ・TF は、ブラウザのタブを非表示にしても配信が止まりません（止まる場合は [トラブルシューティング](troubleshooting.md#カメラ画像や-lidar-の更新が止まる) を参照してください）。
配信されるトピックの一覧は [ROS インターフェース一覧](ros-interface.md) を参照してください。

### LiDAR（`/scan`）

ロボットの周囲 360° を計測する 2D LiDAR を模擬します。

| 項目 | 値 |
|------|----|
| フレーム | `base_scan`（`base_link` から高さ 0.15 m） |
| 計測範囲 | 0.12 m 〜 3.5 m |
| 分解能 | 1°（360 点） |
| 更新周期 | 約 10 Hz |

[ワールド編集](world-editing.md) で配置したオブジェクトが障害物として検出されます。
何も検出しなかった方向は、`range_max`（3.5 m）をわずかに超える値になります。

### オドメトリと TF

| 配信先 | 内容 |
|--------|------|
| `/tf` | `odom` → `base_link`、`base_link` → `base_scan` |
| `/tf_static` | `base_link` → `base_scan` |
| `/onestage/odom` | ロボットのオドメトリ（`nav_msgs/msg/Odometry`） |

SLAM や Nav2 と組み合わせる方法は [ROS インターフェース一覧](ros-interface.md#slam-と組み合わせる) を参照してください。

### カメラ

ロボットのカメラ画像・深度画像は [カメラビュー](camera.md) から配信されます。

## 物体の把持

グリッパーを持つロボットでは、グリッパーを閉じたときに近くのオブジェクトを掴み、ロボットと一緒に動かせます。

1. [ワールド編集](world-editing.md) でオブジェクトを配置します。
2. グリッパーをオブジェクトに近づけ、グリッパーを閉じます。
3. グリッパーの指先からオブジェクトの中心までが一定距離以内であれば、オブジェクトを掴みます。掴んでいるオブジェクトは黄色の枠で囲まれます。
4. グリッパーを開くと、オブジェクトをその場に離します。

把持に対応しているロボットは以下のとおりです。URDF に記載のリンクがすべて含まれていると、自動的に把持が有効になります。

| ロボット | 判定に使うリンク | 開閉を判定する関節 | 把持できる距離 |
|----------|------------------|--------------------|----------------|
| SO-101 | `gripper_link`, `jaw_link` | `gripper` | 8 cm 以内 |
| TurtleBot3（OpenMANIPULATOR グリッパー搭載） | `gripper_left_link`, `gripper_right_link`, `end_effector_link` | `gripper_left_joint` | 10 cm 以内 |

掴んでいるオブジェクトは、ワールド編集で移動できません。
