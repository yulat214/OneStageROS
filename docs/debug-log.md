# デバッグログ

「シミュレータ」タブの右下に表示されるパネルです。
ROS 2 の `/rosout` に出力されるログをリアルタイムに表示し、エラーの原因調査を手助けします。

ヘッダーの「● 接続中」「● 未接続」は ROS Bridge との接続状態です。
ログは新しいものから最大 300 件まで保持されます。

---

## 絞り込み

### ログレベル

`DEBUG` / `INFO` / `WARN` / `ERROR` / `FATAL` のボタンを押すと、そのレベルのログを非表示にします（もう一度押すと再表示）。
「全表示」で、すべてのレベルを表示に戻します。

### ノード

「ノード:」のプルダウンで、特定のノードのログだけを表示します。「解除」ですべてのノードの表示に戻ります。

### 一時停止

ヘッダー右側の ⏸ ボタンで、新しいログの取り込みを一時停止します。
大量のログが流れていて読みにくいときに使います。▶ ボタンで再開します。一時停止中に出力されたログは表示されません。

---

## エラーの調査

`WARN` 以上のログには、以下の機能が使えます。

### 前後5件

「前後5件」を押すと、そのログの直前・直後に出力されたログを、レベルやノードの絞り込みに関係なく表示します。
「↑ さらに5件」「↓ さらに5件」で表示範囲を広げられます。

### システムスナップショット

`WARN` 以上のログを受信すると、その時点で動いていたノードとトピックの一覧を自動で記録します。
ログの左端の ▶ を押すと、記録した一覧を確認できます。ログを出したノードは強調表示されます。

### 日本語訳

スナップショットの欄にある「翻訳する」を押すと、ログのメッセージを日本語に翻訳します。

> 翻訳には外部の翻訳サービス（MyMemory）を使用します。ログのメッセージがインターネット経由で送信されます。

---

## AI 解析

`WARN` 以上のログの「AI解析」を押すと、そのログと前後 5 件のログを AI に送り、推測される原因と確認すべき点を表示します。
結果はログの下に表示されます（▶ で開閉できます）。

### 設定

AI 解析を使うには、OpenAI 互換の Chat Completions API の API キーが必要です。

1. デバッグログのヘッダー右側にある 🤖 ボタンを押して「AI解析 設定」を開きます。
2. 以下を入力して「保存」を押します。

| 項目 | 入力例 |
|------|--------|
| Base URL | `https://api.groq.com/openai/v1` |
| Model | `llama-3.3-70b-versatile` |
| APIキー | 利用する API サービスで発行したキー |

- 既定では [Groq](https://console.groq.com/) の API を使用します。Groq のアカウントを作成し、API キーを発行して入力してください。
- OpenAI など、OpenAI 互換の API であれば Base URL と Model を変更して利用できます。
- 設定はサーバー側の `.env` に保存され、API キーがブラウザに送り返されることはありません。
- API キーを設定すると 🤖 ボタンが緑色になります。

`.env` に直接記述することもできます（[設定](configuration.md) を参照）。

### 解析の指示文を変更する

`.env` の `AI_SYSTEM_PROMPT` に指示文を記述すると、AI への指示を差し替えられます。
説明の詳しさや口調を用途に合わせて変えたい場合に使います。変更後は OneStageROS を再起動してください。

> AI 解析を使うと、ログの内容が設定した API サービスに送信されます。
