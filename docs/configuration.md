# 設定

OneStageROS の設定は、`server/.env` ファイルに記述します。ファイルがなければ作成してください。

```bash
cd ~/OneStageROS
touch server/.env
```

`server/.env` を編集したあとは、OneStageROS を再起動してください（`Ctrl+C` で停止し、もう一度 `npm start`）。

> `server/.env` には API キーなどの秘密情報が保存されます。`.env` は Git の管理対象外に設定されているため、`git push` してもリポジトリには含まれません。

---

## 設定項目一覧

| 変数名 | 既定値 | 説明 |
|--------|--------|------|
| `ONESTAGE_WORLD` | （なし） | 起動時に読み込むワールドファイル。[ワールド編集](world-editing.md#ワールドファイルを起動時に読み込む)を参照 |
| `ONESTAGE_SPAWN` | （なし） | ロボットの初期位置 `"x y yaw"`。[ワールド編集](world-editing.md#ロボットの初期位置)を参照 |
| `GAZEBO_MODEL_PATH` | （なし） | SDF の `model://` を探すディレクトリ（コロン区切り） |
| `AI_BASE_URL` | `https://api.groq.com/openai/v1` | AI 解析に使う API の URL |
| `AI_MODEL` | `llama-3.3-70b-versatile` | AI 解析に使うモデル名 |
| `AI_API_KEY` | （なし） | AI 解析に使う API キー |
| `AI_SYSTEM_PROMPT` | （組み込みの指示文） | AI 解析の指示文を差し替える場合に指定 |

AI 関連の項目は、画面上の「AI解析 設定」から保存することもできます（[デバッグログ](debug-log.md#ai-解析)を参照）。

### コマンドラインで指定する

`server/.env` を使わずに、起動時に環境変数として渡すこともできます。コマンドラインで指定した値は `server/.env` の値より優先されます。

```bash
ONESTAGE_WORLD=ros2_ws/src/my_pkg/worlds/room.world npm start
```

## ネットワーク

Web 画面（3000）・バックエンド（8000）・ROS Bridge（9090・9091）は、すべてのネットワークインターフェースで待ち受けます。
OneStageROS を動かしている PC 以外からは、`http://<OneStageROS を動かしている PC の IP アドレス>:3000` でアクセスできます。

> **注意**: OneStageROS にアクセスできる人は、ホームディレクトリ内のファイルの閲覧・編集や、ターミナルからのコマンド実行ができます。
> 信頼できないネットワークに接続した PC で使う場合は、ファイアウォールなどでこれらのポートへの外部からのアクセスを制限してください。

### Docker で使う場合

コンテナ内で OneStageROS を動かし、ホスト機のブラウザから使う場合は、4 つのポートを転送します。
ポート転送の待ち受けアドレスを `127.0.0.1` にすると、ホスト機以外からはアクセスできなくなります。

```bash
docker run -it \
  -p 127.0.0.1:3000:3000 \
  -p 127.0.0.1:8000:8000 \
  -p 127.0.0.1:9090:9090 \
  -p 127.0.0.1:9091:9091 \
  <イメージ名>
```

docker compose の場合は次のように書きます。

```yaml
ports:
  # 127.0.0.1: を外すと、同じネットワーク上の誰でも OneStageROS（ターミナルを含む）を操作できるようになります
  - "127.0.0.1:3000:3000"
  - "127.0.0.1:8000:8000"
  - "127.0.0.1:9090:9090"
  - "127.0.0.1:9091:9091"
```

> **注意**: `127.0.0.1:` を付けずに `"3000:3000"` と書くと、ホスト機のすべてのネットワークに公開されます。
> Linux の Docker は ufw などのファイアウォールの設定を通らずにポートを公開するため、ファイアウォールだけに頼らないでください。

ホスト機のブラウザからは `http://localhost:3000` で利用できます。
