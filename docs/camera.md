# カメラビュー

「シミュレータ」タブの右上に表示されるパネルです。
シミュレータ内のカメラから見た映像を表示し、カラー画像と深度画像を ROS 2 トピックとして配信します。

---

## 表示モード

ヘッダーの「表示:」のプルダウンで切り替えます。

### ロボットカメラ

ロボットに搭載されたカメラの視点で表示します。

- URDF のリンクのうち、名前に `optical` を含む最初のリンク（例: `camera_color_optical_frame`）をカメラとして使用します。
- カメラのリンクが見つかるまでは「検出中...」と表示されます。見つかると「LIVE」に変わります。

### フリービュー

シミュレータ内を自由な視点から表示します。

| 操作 | 動作 |
|------|------|
| ドラッグ | 視点を回転 |
| `Shift` + ドラッグ | 視点を平行移動 |
| ホイール | ズーム |

「視点を保存」を押すと、現在の視点がブラウザに保存され、次回以降もその視点から表示されます。

---

## 配信のオン・オフ

カメラビューのヘッダー右上のボタンで、カメラ画像の配信を開始・停止します。

| ボタンの表示 | 状態 |
|--------------|------|
| 配信中（緑色のボタン） | カラー画像・深度画像・camera_info をすべて配信しています。クリックすると停止します。 |
| 配信停止中（白色のボタン） | どのトピックも配信していません。クリックすると配信を開始します。 |

- 初めて開いたときは「配信停止中」です。設定はブラウザに保存され、次回以降も引き継がれます。
- 配信中は、購読しているノードがいなくてもトピックが作成されるため、RViz の Image 表示などからトピックを選べます。
- 配信停止中は画像の読み出しも行わないため、PC の負荷が下がります。カメラ画像を使わないときは停止しておくことをおすすめします。

### 配信周期

ヘッダーの「周期:」のプルダウンで、配信周期を `1 Hz` / `2 Hz` / `5 Hz` / `10 Hz` から選びます（既定: `5 Hz`）。
周期を下げるほど PC の負荷が下がります。

---

## 配信するトピック

配信中は、カメラビューに表示している映像を以下のトピックに配信します。

| トピック | 型 | 内容 |
|----------|----|------|
| `/camera/camera/color/image_raw` | `sensor_msgs/msg/Image` | カラー画像（`rgb8`） |
| `/camera/camera/depth/image_rect_raw` | `sensor_msgs/msg/Image` | 深度画像（`32FC1`、単位 m） |
| `/camera/camera/color/camera_info` | `sensor_msgs/msg/CameraInfo` | カメラの内部パラメータ（歪みなし） |

- `frame_id` は、ロボットカメラモードではカメラのリンク名、フリービューでは `free_camera` です。
- 更新周期は、[配信周期](#配信周期) で選んだ値です。PC の処理が追いつかない場合は、自動的に周期を下げます。
- 画像はカメラ専用の ROS Bridge（ポート 9091）経由で配信します。接続できない場合は、通常の ROS Bridge（9090）を使います。
- 画像の解像度は、カメラビューのパネルの表示サイズによって決まります。
- `/camera/color/camera_info` が配信されている場合は、その `width`・`height` に合わせて表示の縦横比を調整します。

RViz の Image 表示や、画像処理ノードの入力としてそのまま利用できます。

> カメラ画像は「シミュレータ」タブを表示している間に配信されます。「エディター」タブに切り替えている間は配信が止まります。
